# 작업 인계 공간

`_workspace`는 복잡하거나 여러 차례 이어지는 작업에서만 사용하는 임시 인계 공간이다. 작은 변경은 불필요한 문서를 만들지 않는다.

## 표준 파일

- `01_request.md`: 사용자 목표, 범위, 제외 사항, 완료 기준
- `02_design.md`: 영향 파일, 계약 변경, 구현 순서, 위험
- `04_validation.md`: 실행 명령, 결과, 실제 동작 확인, 미검증 항목
- `05_review.md`: `통과`, `수정 필요`, `재검토 필요` 판정과 근거

필요한 파일만 만들며 번호와 이름은 유지한다. 비밀값, 토큰, 실제 `.env` 내용, 사용자 데이터는 기록하지 않는다.

## 최소 형식

```markdown
# 제목

## 작업 정보

- 요청:
- 범위:
- 작성 시각:

## 내용

## 남은 항목
```

작업을 마치면 최종 응답이 이 문서의 핵심 결과를 포함해야 한다. `_workspace` 파일을 코드나 제품 문서의 영구적인 사실 출처로 사용하지 않는다.
